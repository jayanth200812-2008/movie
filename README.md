# CineScope — Movie Information Website

A responsive movie-discovery website built with plain HTML, CSS and JavaScript.

## Features
- Movie poster-style cards and featured hero section
- Story/synopsis, cast, director, year, genre, runtime and rating
- Search movies by title or genre
- Genre filter buttons
- Movie detail pop-up
- Trailer preview section and trailer placeholder in each movie detail
- Popular/related movie section
- Responsive layout for desktop, tablet and mobile

## Run it
1. Extract `movie-information-website.zip`.
2. Open the extracted folder.
3. Double-click `index.html` to open it in a browser.

No installation or build tools are required.

## Customize
- Edit the sample movie information in `script.js`.
- Change poster gradients using each movie's `color` value.
- To add a real official trailer, replace the trailer placeholder in `openMovie()` with an official YouTube embed URL.

**Note:** The included titles, cast, stories and ratings are fictional demo content. The poster artwork is created with CSS gradients, so the project works without downloading image files.
